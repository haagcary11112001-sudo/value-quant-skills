# Quant DRIP 分析工作流

A股量化分析完整工作流：业绩-股价收敛测试与耦合DRIP模拟

## 工作流概览

```
Phase 1: 数据获取 → Phase 2: 双耦合验证 → Phase 3: 估值健康度 → Phase 4: DRIP模拟 → 输出PDF
```

## 快速开始

```bash
python3 agents/quant_pdf.py sh.600900 长江电力 3
```

---

## Phase 1: 数据获取

**数据源：** baostock（A股稳定）

**获取字段：**
- 股价：前复权收盘价 (P_t)
- 分红：年度每股派息 (D_t)
- EPS：每股收益
- PE：市盈率TTM

**波动率计算：**
```
σ = std(ln(P_t / P_{t-1}))
```

---

## Phase 2: 双耦合验证测试

### 测试一：双CAGR偏离度

- 分红耦合：|CAGR_P - CAGR_D| < 5%
- EPS耦合：|CAGR_P - CAGR_EPS| < 5%
- **任一通过**即可进入Phase 4

### 测试二：双β与R²

- 分红回归：对 ln(P) 和 ln(D) 线性回归，R² ≥ 0.6
- EPS回归：对 ln(P) 和 ln(EPS) 线性回归，R² ≥ 0.6
- **任一通过**即可进入Phase 4

### 测试三：Z-score

- 计算当前PE的Z-score
- 判断：Z ≤ 1.5 通过

### Cook's Distance 极端值剔除

1. **首次拟合**：不剔除极端值
2. **拟合未通过**：计算 Cook's Distance，删除影响最大的点（Cook's D > 4/n）后重试
3. **仍不通过**：判定为失败，**不回退**

**判断标准：**
- Cook's D 阈值：4/n（n为样本数）
- 剔除上限：10年最多删2年，5年最多删1年，少于5年不得删除
- 剔除后保留不足 80% → 不删除
- 通常剔除 1-2 个高影响年份

---

## Phase 3: 定性判决

| 判决类型 | 条件 |
|---------|------|
| 完美耦合型 | 分红+EPS双验证全通过 |
| 分红耦合型 | 仅分红耦合通过 |
| EPS耦合型 | 仅EPS耦合通过 |
| 泡沫假象型 | 未通过CAGR或R²测试 |
| 估值还债/深坑型 | 未通过CAGR测试，当前极度低估 |
| 部分通过 | 未通过Z-score或其他条件 |

**耦合验证逻辑：**
- 分红耦合：分红CAGR与股价CAGR偏差 < 5%
- EPS耦合：EPS增长率与股价CAGR偏差 < 5%
- **任一耦合通过 + Z-score通过 → 进入Phase 4**

---

## Phase 4: DRIP蒙特卡洛模拟

**执行条件：**
- **必须通过Phase 2双耦合测试**（任一耦合CAGR✅ + R²✅）
- 未通过 → 输出"无法预测"及原因

### 模拟设置

- 模拟期限：3-10年（可自定义）
- 模拟次数：10,000次
- 初始投入：10万元

### 输出指标

| 指标 | 含义 |
|------|------|
| 中位数 | 第5000名的现实预期 |
| 翻倍概率 | 最终财富 > 2.0 的比例 |
| 亏损概率 | 最终财富 < 1.0 的比例 |
| VaR(5%) | 极端回撤底线 |

## 示例输出

**长江电力（sh.600900）：**
- 分红耦合：CAGR偏离1.13%，R²=0.84 ✅
- EPS耦合：CAGR偏离4.95%，R²=0.65 ✅
- Z-score：Z=-0.13 ✅
- 判决：完美耦合型
- 3年DRIP中位数：1.28x

**海信家电（sz.000921）：**
- 分红耦合：CAGR偏离15.97%，R²=0.51 ❌
- EPS耦合：CAGR偏离2.80% ✅，R²=0.59 ❌
- Z-score：Z=-0.91 ✅
- 判决：部分通过（EPS耦合CAGR通过）
- 3年DRIP中位数：1.12x（高波动σ=35.89%）
