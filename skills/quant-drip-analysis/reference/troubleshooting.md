# 故障排查

## 数据获取问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| baostock 连接失败 | 网络问题 | 检查网络连接 |
| EPS数据为负/异常 | 字段索引错误 | 检查 fields 顺序，epsTTM 在 index 7 |
| 分红数据不连续 | 新股分红起步晚 | 使用可用年份数据，避免强制10年 |

## 拟合测试问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 波动率异常小 | 使用了日波动率年化值 | 使用 ln(H/L) 作为年波动率 |
| R² 极低 | 行业周期性过强（证券、能源等） | 参考诊断表，判断为泡沫假象型 |
| 极端值干扰 | 某年份数据异常 | 触发极端值剔除逻辑（Z>2.5） |

## PDF生成问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 中文字体缺失 | 系统缺少中文字体 | 安装中文字体或使用 NotoSansCJK |
| 图表生成失败 | 数据不足 | 确保至少有5年以上数据 |

## "无法预测"判定

Phase 2未通过时，不执行DRIP模拟，输出原因：

| 情况 | 原因 |
|------|------|
| 泡沫假象型 | 股价与基本面严重脱节(R²偏低)，定价受宏观/情绪/概念主导 |
| 部分通过 | 多项耦合测试未通过，DRIP预测不确定性太高 |

**无法预测的可能原因：**
- 股价与基本面严重背离（R²偏低）
- 行业周期性过强（证券、能源等）
- 数据异常/不连续（如新股分红起步晚）
