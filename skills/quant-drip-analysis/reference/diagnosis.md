# 问题诊断参考表

## 分红-股价耦合诊断

| 状态 | 诊断 |
|------|------|
| CAGR✅ + R²✅ | 分红与股价完美耦合，股东回报与股价增长同步 |
| CAGR❌ + 分红>股价 | 分红增长远超股价，公司可能在高估历史估值或留存利润 |
| CAGR❌ + 股价>分红 | 股价涨幅远超分红，估值泡沫风险 |
| 其他 | 分红增长尚可，但R²解释力不足，定价受其他因素主导 |

## EPS-股价耦合诊断

| 状态 | 诊断 |
|------|------|
| CAGR✅ + R²✅ | EPS与股价完美耦合，基本面驱动定价 |
| CAGR❌ + EPS>股价 | EPS增长远超股价，公司盈利能力提升未反映到股价 |
| CAGR❌ + 股价>EPS | 股价涨幅远超EPS，定价脱离业绩基本面 |
| 其他 | EPS增长尚可，但R²解释力不足，定价受宏观/情绪影响 |

## Z-score诊断

| Z范围 | 诊断 |
|-------|------|
| Z < -1 | 严重低估，历史PE低位，DRIP安全边际高 |
| -1 ≤ Z < 0 | 偏低估，PE低于历史均值，具配置价值 |
| 0 ≤ Z < 1.5 | 正常估值区间，PE接近历史均值 |
| Z ≥ 1.5 | 偏高估，PE高于历史均值，小心戴维斯双杀 |

## 判决类型诊断

| 判决 | 诊断 |
|------|------|
| 完美耦合型 | 水电/REITs等刚性需求+稳定现金流资产，股东回报与股价锁定。DRIP策略高度适配。 |
| 分红耦合型 | 分红与股价耦合，但EPS关联弱。适合收息型投资者。 |
| EPS耦合型 | EPS增长驱动股价，但分红未同步。DRIP效果依赖股价稳定性。 |
| 泡沫假象型 | 股价定价脱离基本面！R²极低说明股价受宏观/情绪/概念主导。DRIP效果存疑。 |
| 估值还债/深坑型 | 历史高估值正在消化，PE极低。困境反转标的。 |
| 部分通过 | 多项测试未通过，需谨慎评估。 |
